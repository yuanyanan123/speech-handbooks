这本手册怎么读

这本手册只做一件事：跟着一段声音，从麦克风走到喇叭。一组多通道语音进来，先被前端清理，再被识别成文字，经过理解产生回复，再被合成为声音播出去——而播出去的声音又会被麦克风收进来。整条链路是一个闭环。

每一节讲链路上的一步，并且每一步都按同一个顺序写：原理与推导 → 先进方法 → 评价 → 工程问题 → 交接卡。交接卡回答四个问题：这一步吃什么、吐什么、靠什么假设成立、假设破了以后下游看到什么。把相邻两步的交接卡对起来读，就是整条链路的架构。

这本手册与另外三本的关系。前端信号处理手册、ASR 链路手册、TTS 合成手册各自把一个方向讲得更深，并带有实验；这一本负责把它们串成一条完整的链路，并把每一步的核心推导写清楚。每节末尾会指出去哪本手册看实验和细节。这一本没有实验，不含任何实测数字；出现的数字都是算术（如帧数、形状）或定义。

01观测模型与数据形状：一段数据的一生入门

前端的所有算法，其实都是在回答同一个问题：麦克风听到的这一串数，是哪几个东西叠加成的？每一步处理就是在叠加里拆掉一项。

一句话版

麦克风信号 = 目标语音（经房间）+ 自己播放声音的回声 + 噪声。阵列拆空间、回声消除拆参考、单通道增强拆统计。数据在链路上不断变换形状，先把形状账算清楚，后面才不会在接口上出错。

原理与推导

时域模型。第 m 个麦克风在第 n 个采样点听到的信号，是三项的叠加：

频域模型。对每一帧做短时傅里叶变换（STFT）。卷积在频域变成乘法，但这个"乘法"有一个前提：帧长要远大于冲激响应的长度，这样帧边界处被截断的那一小部分才可以忽略。满足时，每个频点上有：

导向矢量的推导很直接：平面波沿方向 u 传播，到达位置 pm 处比到达原点早（或晚）pm⊤u/c 秒；时延 τ 在频点 fk 上对应相位 −2πfkτ。混响长时（帧长不满足上面的前提）时，这个乘法模型只是近似，精确的写法是对帧间做卷积（卷积传递函数模型），去混响（5 节）就建立在这个更精确的模型上。

闭环

把整条链路写成一个复合映射：前端 𝓕、识别 𝓐、理解与回复 𝓡、合成 𝓣。麦克风信号进入 𝓕，最终输出播放信号 x，x 经房间路径又进入 y：

链路是闭环

x[n]=T(R(A(F(y[≤n],x[≤n])))),y[n] ∋ (g∗x)[n]  （输出又回到输入）
𝓕前端：阵列、回声消除、增强𝓐识别𝓡理解与回复𝓣合成

这个闭环是全书的主线。它意味着：模块不能只在开环下评价。前端的失真会影响识别，识别的错误会影响回复，回复的声音又会变成前端的干扰。第 14 节专门讲闭环。

02阵列：用空间信息拆开目标与干扰进阶

多个麦克风的价值只有一个：同一个声源到达各个麦克风的时间不同。这个差异就是空间信息。

一句话版

波束成形 = 给每个通道乘一个复权重再相加，让目标方向相干叠加、其他方向相互抵消。延迟求和（DAS）稳，MVDR 抑制强但对失配敏感，两者之间是一条用对角加载调节的连续谱。

原理与推导

1. 延迟求和（DAS）。目标方向的导向矢量是 a。要求目标无失真，即 wHa = 1。最简单的取法是 w = a/M：每个通道只做相位对齐（补偿到达时间差），然后平均。对目标：wHa = aHa/M = 1。对各通道互不相关的白噪声（如麦克风自噪声）：输出噪声功率 ∝ wHw = 1/M，所以信噪比提升 M 倍：

DAS 与白噪声增益（WNG）

WNG白噪声增益：对不相关噪声的信噪比提升M麦克风数

3. 弥散场与指向性指数。对混响房间里的弥散噪声，理想的各向同性场里两个全向麦克风之间的相干函数是 sinc 形的，间距越大、频率越高，相干越低。用它作噪声协方差得到"超指向"波束；衡量指标是指向性指数 DI（目标方向增益对所有方向平均增益之比）。同时给出另一个重要上限：麦克风间距 d 决定空间混叠，频率高于 c/(2d) 时，不同方向会产生相同的相位差，波束出现栅瓣。

03回声消除：用已知的参考把自己的声音减掉进阶

设备自己在播声音，麦克风又把它收进来。好在这个声音是已知的：它的数字副本就是参考信号。

一句话版

回声消除是一个系统辨识问题：用参考 x 估计回声路径，预测回声再减掉。难点不在辨识本身，而在近端说话时不能学、路径会变、喇叭不线性，以及延迟与时钟对不齐。

原理与推导

1. 模型。麦克风信号 y = d + s + v，其中 d = h∗x 是回声（h 是 L 点的回声路径），s 是近端语音，v 是噪声。自适应滤波器用权重 w（目标是逼近 h）从参考的最近 L 个样本 x[n] = [x[n], …, x[n−L+1]]⊤ 预测回声，误差 e = y − x⊤w 就是消除后的输出。

2. NLMS 的推导（最小扰动原理）。每来一个样本，希望权重"改得尽量少"，同时让这个样本上的误差归零：

NLMS 的推导

​w′min​ ∥w′−w∥2s.t.x⊤w′=y  (一次更新后，当前样本的误差归零)⟹ w′=w+μx⊤x+δex​,e=y−x⊤w​
μ步长，0 < μ < 2δ防止除零的小常数L滤波器长度

用拉格朗日乘子解这个约束最小范数问题：令 Δw = w′ − w，约束 x⊤Δw = e，最小范数解是 Δw = ex/(x⊤x)。再乘上一个步长 μ 是为了不完全"一步到位"：噪声 v 的存在会让一步到位把噪声也学进权重里。分母的 x⊤x 让更新量与输入功率无关——这就是"归一化"。

3. 快与准的乘积。在输入为白噪声等标准假设下，收敛的时间常数与稳态的额外误差分别是：

NLMS 的收敛与稳态

τ收敛​≈μ(2−μ)L​ （样点）,M稳态​≈2−μμ​σv2​ ⟹ τ⋅M≈(2−μ)2Lσv2​​  (μ≪1 时几乎不随 μ 变)
τ收敛的时间常数（样点）M稳态稳态额外均方误差σv2近端噪声功率

这个乘积几乎不随 μ 变化：想收敛得快就要大步长，大步长稳态就差；快与准不能同时得到。这是自适应滤波的基本约束，后面所有"进阶方法"（分区块、卡尔曼、双路径）本质上都是在不同的维度上缓解它。

4. 频域与分区块。房间冲激响应很长（几百毫秒、几千个样点），时域 NLMS 每个样点要 L 次乘加，算力太大。把滤波器按块切开，用 FFT 做块卷积（重叠保留法），每个频点一个小滤波器，并且每个频点独立归一化——这样语音这种在不同频率上能量差几十 dB 的信号，不同频点各自以合适的步长收敛（时域 NLMS 对有色输入收敛很慢，原因是输入自相关矩阵的特征值扩展）。块长决定延迟，分区数决定覆盖的路径长度，二者解耦。

5. ERLE 与它的上界。用回声损耗增强来量化消除了多少。需要注意：线性滤波器的 ERLE 有一个硬上界，由参考与回声之间的相干性定——只要回声里有参考线性解释不了的部分（非线性失真、时变路径、噪声），上界就有限。

ERLE 与它的相干性上界

ERLE=10log10​E[(d−d^)2]E[d2]​,ERLEmax​=−10log10​(1−γxd2​)
d回声d̂回声估计γxd2参考与回声的幅度平方相干

先进方法

双讲检测（DTD）。近端人说话时，误差 e 里含近端语音，滤波器会把它当成"没学好的回声"去追，权重被带偏。传统办法是检测到近端说话就冻结更新（能量比、相干性）。检测错误的代价是不对称的：漏检会让权重被带偏，短时间内可能发散；误检只是少学了一点。

γ 越大，回声压得越狠，近端语音也伤得越狠——这是一条取舍曲线，不是一个单调变好的旋钮。神经方法（神经 RES、混合式 AEC）能学到非线性产生的谐波结构，是目前最有效的进展方向，但它们改善的是同一近端损伤下的 ERLE，没有消除取舍。

04单通道增强：只剩一路信号时，还能拆什么进阶

空间信息用完了、参考也用完了，剩下一路信号里还有噪声。这时能依赖的只有统计规律：噪声比语音平稳，语音在时频上稀疏。

一句话版

经典方法 = 估计噪声功率 → 估计先验信噪比 → 套一个增益。三步里最难的是第一步和第二步。神经方法绕过了估计，直接学增益，但物理上的失真—降噪取舍依然在。

原理与推导

1. 维纳增益。假设 Y = S + N，语音与噪声不相关。要找一个增益 G，使 Ŝ = GY 的均方误差最小：

维纳增益的推导

​Y=S+N,S⊥N:E∣S−GY∣2=(1−G)2Φs​+G2Φn​∂G∂​=0 ⇒ −2(1−G)Φs​+2GΦn​=0 ⇒ GW​=Φs​+Φn​Φs​​=1+ξξ​,ξ=Φn​Φs​​​
Φs, Φn语音与噪声的功率谱ξ先验信噪比

展开 E|S − GY|² = (1 − G)²Φs + G²Φn（交叉项因不相关为零），对 G 求导令其为零，得到 G = Φs/(Φs + Φn)。这个式子的直觉是：每个时频点按"语音占总能量的比例"衰减。先验信噪比 ξ 是真正的关键——它需要知道语音功率，而语音功率恰恰是未知的。

2. 谱减法与维纳的关系。谱减法从另一个角度出发：从带噪功率里减去噪声功率估计。引入后验信噪比 γ = |Y|²/Φn（可以直接观测），功率谱减是 |Ŝ|² = |Y|² − Φn，对幅度的增益是 √(1 − 1/γ)（并设下限 β 防止负值）。

γ后验信噪比（可观测）β谱减的下限ξ先验信噪比（不可观测，需估计）

两者形式相近：把先验信噪比换成这一帧的瞬时估计 ξ̂ = γ − 1 代入维纳增益，得到 1 − 1/γ，功率谱减的幅度增益是它的平方根。区别在于：谱减用的是这一帧的瞬时观测γ，维纳用的是先验ξ（语音功率的期望）。瞬时观测波动大，减出来的负值被截断成随机的孤立亮点，听起来是"音乐噪声"。

3. 先验信噪比的估计：决策导向（DD）。ξ 不可观测，Ephraim–Malah 的办法是把"上一帧估出来的干净语音功率"和"这一帧的瞬时估计"做加权：

α 接近 1 让 ξ̂ 在时间上平滑，抑制了音乐噪声；代价是对语音起音有"拖尾"（上一帧没有语音的地方，这一帧的语音起始被压得太狠）。

4. 更好的增益：MMSE-STSA 与 log-MMSE。维纳增益是对复谱的最小均方估计，但人耳对幅度（尤其是对数幅度）更敏感。Ephraim–Malah 在语音与噪声的复谱是高斯分布的假设下，推导了对幅度的最小均方估计（MMSE-STSA）与对数幅度的最小均方估计（log-MMSE，亦称 LSA）。LSA 的增益在维纳增益的基础上多乘一个由指数积分决定的因子：

先进方法

06特征提取：从波形到梅尔对数谱入门

识别模型不直接吃波形（至少传统上不是）。波形到特征这一步丢掉了什么、保留了什么，决定了下游模型的上限。

一句话版

波形 → 加窗分帧 → 功率谱 → 梅尔滤波 → 取对数。其中最重要的一步是取对数：它把"信道乘法"变成"加法"，使一个均值归一化就能消掉信道。

原理与推导

1. 短时平稳。语音在 10–30 ms 的尺度上近似平稳（声道形状来不及显著变化），所以在这个尺度上做傅里叶变换有意义。常见取法：窗长 25 ms、帧移 10 ms，窗用汉宁窗或汉明窗以减少频谱泄漏。

2. 预加重、梅尔滤波、对数。预加重是一个一阶高通，补偿语音频谱的高频下倾；梅尔刻度模拟人耳在低频分辨率高、高频低的感知；每个三角滤波器对功率谱求加权和，得到 80 维左右的能量，再取对数：

预加重、梅尔刻度与对数梅尔特征

​x~[n]=x[n]−0.97x[n−1]  (预加重),mel(f)=2595log10​(1+700f​)Ej​(t)=k∑​Hj​(k)∣Y(t,k)∣2,o(t)=[logE1​(t),…,logE80​(t)]⊤​
Hj(k)第 j 个三角滤波器在频点 k 的权重Ej(t)第 t 帧第 j 个滤波器的能量o(t)特征向量

3. 为什么取对数：同态处理。麦克风信号等于干净语音的频谱乘上信道（麦克风与房间的稳定部分）的频率响应。对数把乘法变成加法：

对数把信道变成加性常数

log∣Y∣2=log∣S∣2+log∣H∣2 ⟹ o^(t)=σo​o(t)−μo​​  (均值里的 log∣H∣2 被减掉)
H信道的频率响应（一段话内近似不变）μo, σo一段话内特征的均值与标准差

如果信道 |H|² 在一句话内基本不变，那么 log|H|² 对每个频带是一个常数，它会整体平移这个频带的特征均值。减去均值就把它消掉了（倒谱均值归一化，CMN；再除以标准差就是 CMVN）。同样的道理：整体增益的变化也是一个对数域的常数平移，被均值归一化消掉。这就是为什么特征归一化让识别对麦克风、音量不敏感。

4. 离散余弦变换（MFCC）。对数梅尔相邻频带高度相关；传统系统用对角协方差的高斯混合模型，需要去相关。对对数梅尔做离散余弦变换并保留前十几维就是 MFCC。今天的深度模型不需要去相关，直接用对数梅尔，保留了更多信息。

先进方法

  • PCEN：每个频带带自适应增益控制的对数替代，对增益变化与稳态噪声更稳。
  • 可学习前端：用卷积网络直接处理波形（如自监督模型的特征编码器），把"滤波器组"也交给训练。优点是不预设梅尔；代价是对信号域的变化（采样率、增益）更敏感。
  • 多通道特征：在对数梅尔之外加入通道间相位差（IPD）等空间特征，让识别模型自己利用空间信息。
  • SpecAugment：在对数梅尔上做频带与时间的掩蔽，是最常用的数据增强（ASR 手册 34 节）。

01为什么对数梅尔特征做均值归一化就能消掉信道的影响？

看答案
信道是频谱上的乘法，取对数后变成加法，一句内近似为每个频带上的常数；减去均值就消掉了。整体音量的变化也是同一个道理。

07识别建模：从 HMM 到端到端深入

语音识别的核心难题是对齐：音频有几百帧，文字只有十几个字，哪一帧对应哪个字没有人标注。所有识别方法的差别，都是怎么处理这个对齐。

一句话版

HMM 把对齐写成隐状态路径，CTC 用 blank 把对齐写成"允许重复与空白的路径"，RNN-T 让模型自己决定何时输出，注意力模型绕过显式对齐。四者都是对所有对齐求和或最优。

原理与推导

1. 贝叶斯分解（所有系统的共同起点）。给定音频特征 X，找最可能的词序列 W。用贝叶斯公式，P(X) 与 W 无关，可以丢掉：

P(X|W)声学模型：这个词序列发出这段声音的概率P(W)语言模型：这个词序列本身出现的先验

2. HMM：对齐是隐状态路径。把每个音素建模成几个状态的左右型 HMM，状态之间有转移概率 aij，每个状态按发射概率 bj(o) 产生一帧特征。对所有状态路径求和得到总概率（前向算法），取最优路径得到对齐（Viterbi）。两者的区别只是求和与取最大：

推导前向公式的思路：到第 t 帧停在状态 j 的路径，一定是从第 t−1 帧的某个状态 i 转移过来，再发射当前帧；对所有 i 求和就是递推。复杂度是 O(T·N²)（N 是状态数），否则要枚举指数多条路径。混合系统（DNN-HMM）里，神经网络输出的是状态后验 P(j|o)，而 HMM 需要的是似然 p(o|j)；贝叶斯公式给出 p(o|j) = P(j|o)p(o)/P(j)，p(o) 对所有状态一样，可以略去，所以发射概率正比于后验除以状态先验。

CTC 的两个性质要记住：（1）条件独立假设——给定输入，各帧输出相互独立，所以它没有内置的语言模型，需要外接；（2）尖峰行为——训练后网络倾向于在少数帧上输出非空白标签（尖峰），其余帧输出空白，因为空白路径的总数最多。

4. RNN-T：让模型自己决定何时输出。RNN-T 在 CTC 的基础上加一个预测网络（只看已经输出的标签，充当内置的语言模型）和一个联合网络（结合编码器第 t 帧与预测网络第 u 个状态，输出下一个符号或空白）。路径在一个 (t, u) 格子上走：输出空白表示"看下一帧"（t+1），输出标签表示"留在这一帧、再多说一个字"（u+1）。

08解码与语言模型：声学分数之外的东西进阶

声学模型只给出每一帧"像什么"，把它们变成一句话，还要靠语言模型的先验和一个搜索过程。

一句话版

解码是在"声学分数 + 语言分数 + 长度惩罚"上做搜索。搜索不是越宽越好，因为模型分数最高的句子不一定是对的那句。

原理与推导

1. 打分函数。在端到端系统里，最常用的是浅融合：对每个候选序列，把声学分数、外部语言模型的分数和长度奖励线性组合。如果声学模型内部已经隐含了一个语言模型（RNN-T 的预测网络、注意力解码器），外接语言模型会"重复计数"文本先验，所以要减去内部语言模型（ILM）的估计分数：

λ、β、μ 要在同一份开发集上联合调。λ 太小，先验不起作用；λ 太大，输出通顺但与音频无关，且倾向于删除（短句的语言模型得分更高）。β 调节的是同一件事的长度侧。

2. n-gram 语言模型与平滑。n 元模型用计数估计条件概率，但大量合法的 n 元组在训练语料里从没出现，最大似然估计会给它们零概率。平滑的思路是把一部分概率质量从见过的 n 元组"拿出来"，分给没见过的。Kneser–Ney 平滑是最常用的一种：绝对折扣 d，再用"低阶分布"补偿，低阶分布用的是续接概率（一个词能跟在多少种不同的词后面），而不是它自己的频次。

续接概率的直觉：词"Francisco"频次很高，但它几乎只跟在"San"后面；在"没见过的上下文"里预测下一个词时，不应该因为它频次高就给它大概率——它的续接概率很低。困惑度是对数似然的指数化平均，可理解为"平均每一步在多少个等可能的词里选"。困惑度低不等于识别率高：语言模型是否帮得上忙，取决于它与声学模型的互补程度。

3. beam search。维护得分最高的 B 个部分假设，每一步扩展、打分、保留前 B 个。B = 1 是贪心。B 越大，越接近"模型眼里分数最高的序列"。但分数最高不等于最准确：模型可能系统性地偏爱某类错误（太短、太通顺），B 开得越大越容易找到这些错误；所以增大 B 后错误率反而上升是可能的，要在开发集上扫。

4. WFST：传统系统的一体化搜索图。把 HMM 拓扑（H）、上下文依赖（C）、发音词典（L）、语言模型（G）四个有限状态转换器复合成一个图 HCLG，再做确定化、最小化，得到一个紧凑的搜索图，解码就是图上的最优路径搜索。优点是语言模型和词典在构图时就固化、搜索极快；缺点是要重新构图才能改词表（热词动态加入较难）。

先进方法

  • 两遍解码与重打分：第一遍用小模型出 N-best 或格，第二遍用大语言模型重打分，兼顾延迟与精度。
  • 最小贝叶斯风险（MBR）解码：不选后验最大的假设，而选在 N-best 内期望错误最小的假设，倾向于"共识"。
  • 上下文偏置：把热词构成前缀树，在搜索时对匹配的路径加分（要防止过度偏置把常见词替换成热词）。
  • 后处理：逆文本规范化（把"二零二四年"变成"2024 年"）、标点恢复、大小写——它们不改变声学内容，但改变评测与下游体验。

09文本中枢：理解、回复与交给合成的方式进阶

识别的输出是文字，合成的输入也是文字，中间还有一段：理解用户要什么、决定回什么。它不是本书的重点，但它决定了识别的错误怎样传播、合成该从什么时候开始。

一句话版

文本中枢的难点不在生成本身，而在三个接口：识别的不确定性怎么传进来、回复什么时候开始流出去、被打断时怎么收场。

原理

1. 输入接口：不只是一个字符串。理想情况下，识别交给文本中枢的是带不确定性的文本：N-best 或格、词级置信度、时间戳、说话人。只给 1-best 的字符串会丢掉这些信息。把识别当作"上游的一个噪声信道"，下游的任务是在这个信道上做推断：同音字与近音词的混淆、专名、数字，最好用 N-best 与发音相似度来判断，而不是信 1-best。

2. 理解与决策。传统做法是意图分类与槽位填充；现在大语言模型直接生成回复或调用工具。两者共同的要求：对识别错误稳健（训练或提示时见过带错的识别文本）、在置信度低时会追问而不是硬猜。

3. 输出接口：流式、分句、规范化。语言模型逐词生成，合成需要完整的一小句才能给出自然的韵律。常用做法是按标点或语义边界分句，第一句一生成完就送给合成，同时继续生成后面的。分句策略决定首音延迟与韵律自然度的取舍：句子切得短，首音早，但跨句韵律断裂；切得长则相反。送进合成前还要做文本规范化（数字、符号、缩写展开为读法）。

10文本前端：规范化、发音与韵律入门

合成不是把字直接变成声音。字要先变成"怎么读"：数字怎么读、哪个音、在哪停顿、哪里重读。

一句话版

文本前端回答三个问题：读什么（规范化）、怎么发音（G2P）、怎么说（韵律）。它不起眼，但同一个字读错，后面的声学模型再好也救不回来。

原理

1. 文本规范化（TN）。把书写形式变成读法：数字（"2024 年"读"二零二四年"，"3.5"读"三点五"）、单位（"5kg"）、日期、符号、缩写。它是上下文相关的：同样是"1/2"，在日期里读"一月二日"，在分数里读"二分之一"。规则 + 有限状态转换器是传统做法，现在常用神经模型或语言模型做补充，但歧义大的类别（电话号码、金额）仍要靠规则兜底，因为这些读错的代价很大。

2. 字到音（G2P）。把文字转成音素序列。可以写成在给定字符序列下对音素序列的最大后验估计；难点在多音字——同一个字符在不同上下文里读音不同，所以条件里必须包含上下文：

3. 韵律。韵律是语音里文本没写出来的那部分：停顿、重音、语调、语速。从文本预测韵律是一对多的：同一句话有许多合理的说法。传统做法是预测韵律边界（词、短语、句子级的停顿层级）；神经模型则把韵律隐含在声学模型里，用时长、基频、能量预测器或随机采样产生。基频常用半音刻度表示（s = 12·log₂(f₀/fref)），因为人对音高的感知接近对数。

先进方法

  • 多音字消歧：用预训练语言模型的上下文表示判断读音，比规则准。
  • 跳过显式前端：大语言模型驱动的合成直接用字符或子词作输入，由模型自己学会读法——省去了前端的工程，代价是对罕见读法、数字与专名的可控性变差，需要 SSML 或显式标注兜底。
  • 多语种与语码转换：先分语种，再分别 G2P，在切换点处理韵律重置（TTS 手册 30、38 节）。

11声学模型：从音素到梅尔谱，以及"一对多"深入

语音合成与识别最大的不对称是：识别有唯一答案，合成没有。同一句话有无数种合法的读法，而损失函数只能给出一个答案。

一句话版

用均方误差训练的合成模型，最优解是条件均值，听起来是被"平均"后的模糊声音。一代代方法本质上都在回答同一个问题：怎样让模型采样一种合理的读法，而不是输出所有读法的平均。

原理与推导

1. 为什么回归会糊。设条件 c（文本、说话人）下目标 x（梅尔谱）有多种合理取值。用均方误差训练一个确定性函数 f(c)：把 x − f(c) 拆开，加减条件均值 E[x|c]，交叉项因条件期望的性质为零，得到：

均方误差回归的最优解

E∥x−f(c)∥2=与 f 无关：一对多的方差E∥x−E[x∣c]∥2​​+E∥E[x∣c]−f(c)∥2 ⟹ f∗(c)=E[x∣c]
E[x|c]给定条件 c 时目标的条件均值

第一项是数据本身的方差（一对多），与模型无关，永远消不掉；第二项在 f(c) = E[x|c] 时为零。所以最优的确定性输出是所有读法的平均：平均的基频轨迹没有清晰的起伏，平均的共振峰边界模糊——这就是"电音""闷""平板"的来由。

2. 时长与对齐。文本与梅尔谱的长度不同，必须决定每个音素占多少帧。两条路：（a）注意力自己学对齐（Tacotron 一族）——灵活但没有结构约束，会跳字复读；（b）显式时长：由时长预测器给出每个音素的帧数，再按帧数把音素的隐状态展开（长度调节器），这样总帧数 T = Σ di，对齐天然单调。

4. 流匹配的推导。流匹配学一个时变向量场 v，使得沿它积分，能把简单分布（标准正态）搬运成数据分布。最简单的构造是条件路径：取一个噪声样本 x₀ 和一个数据样本 x₁，用直线连起来。沿这条直线，位置是 xt = (1−t)x₀ + t·x₁，速度恒为 x₁ − x₀。让网络回归这个速度：

5. 采样与步数。用数值积分（如欧拉法）求解常微分方程，步长 Δ = 1/NFE。步数越多，积分越精确，但每一步都要跑一次网络。实时系统里 NFE 直接决定延迟（TTS 手册 40 节讨论少步方法）。

6. 引导（CFG）。训练时随机丢掉条件，让同一个网络既能做有条件、也能做无条件预测；采样时把两者之差放大：

无分类器引导

v~=vθ​(x,t,c)+s(vθ​(x,t,c)−vθ​(x,t,∅))(s=0 即无引导，每步多一次前向)
s引导强度∅空条件

s 越大，输出越贴合条件（文本、说话人），但多样性下降；它以多样性换遵循度，并且每一步多一次前向，成本翻倍。

先进方法

  • 零样本克隆：把一段参考语音（及其文本）作为提示，模型在提示的上下文里"续写"，不更新参数就能模仿音色（TTS 手册 20 节）。
  • 非自回归 + 填充：把参考语音的一部分遮住，让模型根据文本和未遮部分补全，统一了合成、编辑与克隆。
  • LLM-TTS：文本 + 说话人提示 → 语言模型自回归生成离散语音 token → 解码器还原波形；继承语言模型的上下文理解，代价是长序列、采样不稳定和延迟。
  • 偏好优化与强化学习：用可懂度、相似度、人工偏好作奖励继续优化（TTS 手册 39 节）；奖励会被钻空子，需要独立评估。

12声码器与神经编解码：从梅尔谱回到波形进阶

梅尔谱丢掉了相位，也丢掉了精细的谐波结构。声码器的任务是把它们"猜"回来。

一句话版

声码器是一个条件生成器：梅尔谱进去，波形出来。现在的主流是对抗训练的卷积声码器；神经编解码器把波形压成少量离散码，成为 LLM-TTS 的基础。

原理与推导

1. 梅尔谱丢了什么。梅尔滤波把相邻频点合并（高频合并得更多），所以精细的谐波结构（基频的整数倍）被抹平；取幅度又丢掉了相位。早期的 Griffin–Lim 算法迭代地"猜"相位：反复在 STFT 域与时域之间来回投影，直到一致，但结果带金属音。

2. 对抗训练的声码器（HiFi-GAN 一族）。生成器：把梅尔谱经转置卷积逐级上采样（上采样总倍数等于帧移）直到波形长度。判别器：多个，分别看不同周期（多周期判别器）与不同尺度（多尺度判别器）的波形片段。训练用最小二乘 GAN 的目标，并加两项辅助损失：特征匹配（判别器中间层特征的距离）与梅尔谱 L1：

3. 其他声码器。自回归（WaveNet）质量高但逐点生成极慢；流式（flow）可并行；扩散声码器多步迭代；傅里叶系（预测 STFT 再逆变换）算力低。选择取决于算力与流式要求。

听测要多少样本。听测的功效取决于评分的方差与你要分辨的差距：所需评分数与可分辨差距的平方成反比：要分辨 0.1 分的差异，需要的评分数是分辨 0.5 分的 25 倍。所以做对比时要固定文本、说话人与顺序随机化，并且报告置信区间——差距落在区间里，就不能说谁更好。

流式合成

流式合成的目标是缩短首包延迟：从文本到第一块音频的时间。做法是把文本分块、逐块合成，并让声学模型与声码器各自按块输出。三处边界要处理：（1）文本块边界：块之间的韵律（语调延续、停顿）；（2）声学块边界：自回归模型保留状态，非自回归模型要有重叠；（3）声码器块边界：感受野要求相邻块有重叠或缓存状态。

安全：伪造、水印与同意

合成越逼真，滥用风险越大：冒充他人声音诈骗、伪造证据。工程上的三道防线：同意（克隆别人的声音必须有授权，并留存证据）、水印（在合成语音里嵌入难以察觉、能抵抗压缩与重录的标记，便于溯源）、检测（识别合成语音，但与生成器之间是持续的对抗）。水印会随压缩、重采样、播放再录制而衰减，要在这些变换后复测检出率。
